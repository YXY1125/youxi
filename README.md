# 压力大爆破

一款面向移动端与桌面端的零依赖打地鼠解压小游戏。源码为本项目重新设计和实现，没有复制第三方图片或音频素材。

## 玩法

- 锤普通烦恼地鼠得 1 分，锤金色好运得 3 分。
- 每 5 次连续命中触发额外加分。
- 不要锤摸鱼猫：误伤扣 2 分并清空连击。
- 提供 30 秒「松弛局」和 20 秒「暴走局」。
- 支持触屏、鼠标、数字键 1–9、空格暂停、音效开关与自动暂停。
- 结算页、底部工具区和品牌标识均可返回游戏首页。
- 首页形象库支持多选混搭普通烦恼，每次冒头都会从已选形象中随机抽取；金色好运和白色风险目标保持独立单选。当前提供原生地鼠、原创双状态「加活领导」「无效会议（PUA 高管）」「催租房东」与「傲慢精英」、「天降横财」金色奖励，以及原创「摸鱼白猫」风险形象，并在本机记住选择。

## Android

`android/` 是零网络依赖的原生 WebView 壳。网页资源会内置到 APK，手机上直接点击九宫格即可操作；系统返回键会优先回到游戏首页。

Android 1.4.1 起，构建脚本会在签名前统一 APK 内部资源路径为正斜杠，确保所有自定义 PNG 形象可被 WebView 正常读取。

## 本地运行

直接打开 `dist/index.html`，或用任意静态文件服务器托管 `dist/`。

## 开源实现调研

开发前参考了以下项目的公开说明与玩法结构，仅用于理解定时刷新、难度曲线与命中反馈：

- christopherscott/whackamole — MIT，原生 JavaScript 状态控制思路。
- kubowania/whac-a-mole — 原生 JavaScript 九宫格教程实现。
- hunterfront/little-program — 多地鼠、关卡、命中率、暂停机制。
- mashukui/web-games — MIT，黄金目标、炸弹/风险目标的玩法层次。
- howcode/FrightMouse（Gitee）— 移动端适配与多目标反馈；仓库未指定许可证，因此未复用代码或素材。

第三方项目的许可证与最新状态请以各自仓库为准。

完整链接与许可证核查说明见 `SOURCES.md`。
